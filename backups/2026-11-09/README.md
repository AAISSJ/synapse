## 범위

휴지통의 이전 원문·수집함·개인 정리·용어·비교표·에이전트 대화·요약 리비전까지 포함합니다. 로그인 세션·API 토큰·GitHub 인증 정보·작업 임대 정보는 제외합니다. JSON은 사용자 콘텐츠 스냅샷이며 인증 DB 덤프가 아닙니다. 자동 복원 도구는 포함하지 않습니다. 복구 시 대상 계정·원래 ID 연결·이미지 재업로드 및 URL 매핑이 필요합니다.
