# Java

주제: 컴퓨터 언어

JVM을 기반으로 자동 메모리 관리와 넓은 서버 생태계를 제공하는 언어다.

## 용어

### JVM

Java 바이트코드를 실행하고 GC·JIT 등 실행 서비스를 제공하는 가상 머신이다.

### 바이트코드

특정 CPU 기계어 대신 가상 머신이 처리할 중간 명령 표현이다.

### GC

도달할 수 없는 객체의 메모리를 자동 회수하는 방식이다.

### 가상 스레드

JVM이 플랫폼 스레드에 배치하는 경량 스레드로 Java 21에서 정식 도입되었다.

## Go와 비교하는 기준
Sun Microsystems의 James Gosling 등이 개발해 1995년 공개했다. 일반적으로 바이트코드로 컴파일한 뒤 JVM에서 실행하며 JVM은 JIT 등을 통해 최적화한다. 네이티브 이미지 같은 다른 배포 방식도 존재한다.

GC와 성숙한 서버 라이브러리·운영 도구가 강점이다. 전통적인 플랫폼 스레드 외에 Java 21에서 정식 도입된 가상 스레드로 많은 I/O 작업을 다룰 수 있다.

Go는 네이티브 실행 파일 중심 배포와 작은 언어 기능 집합을 선호한다. Java는 JVM 생태계와 풍부한 추상화를 제공한다. 실제 메모리·지연·개발 비용은 워크로드와 구현에 따라 비교해야 한다.
