# 인덱스

다른 이름: Index · 인덱싱

주제: DB

조회 경로를 빠르게 찾는 보조 자료구조. 쓰기 비용·저장 공간과 균형을 잡는다.

## 용어

### 복합 인덱스

다른 이름: Composite index

여러 컬럼을 묶은 인덱스. 컬럼 순서와 실제 조건·정렬·선택도가 사용 가능성과 성능에 영향을 준다.

## 인덱스의 역할
인덱스는 특정 조건의 데이터를 빠르게 찾도록 돕는 보조 자료구조다. 실제 WHERE·JOIN·ORDER BY 패턴과 데이터 분포를 기준으로 설계한다.

## 성능과 비용
조회가 빨라질 수 있지만 INSERT·UPDATE·DELETE 시 인덱스 유지 비용이 발생하고 저장 공간도 추가로 사용한다.

**복합 인덱스**는 컬럼 순서가 중요하다. 조건의 형태·선택도·정렬 요구에 따라 활용 범위가 달라진다.

==컬럼이 쿼리에 등장한다는 이유만으로 인덱스를 만들기보다, 실행 계획과 실제 지연 시간으로 효과를 확인한다.== EXPLAIN 등으로 전체 스캔 여부와 선택된 접근 경로를 점검한다.
