## 기원
Facebook의 Jordan Walke가 만들었다. 뉴스피드 개발에서 처음 쓰였고 2013년 5월 JSConf US에서 오픈소스로 공개되었다. 상태가 바뀔 때마다 화면 일부를 직접 고치는 방식의 복잡도를 줄이려는 목적에서 출발했다.

## 설계 특징
화면을 상태의 결과로 선언하는 방식이다. 컴포넌트는 props와 state를 입력으로 받아 UI 구조를 반환하고, 상태가 바뀌면 React가 이전 결과와 비교해 필요한 부분만 갱신한다. 이 과정이 DOM 조작을 직접 작성하지 않아도 되게 한다.

JSX는 JavaScript 안에서 UI 구조를 쓰는 문법 확장이다. 브라우저가 직접 실행하지 않으며 Babel·TypeScript·SWC 같은 도구가 일반 JavaScript 호출로 변환한다. JSX 없이도 React를 쓸 수 있다.

```tsx
function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}
```

`useState` 같은 Hook은 함수 컴포넌트에서 상태와 생명주기 기능을 쓰게 해 주며 React 16.8(2019년)에서 추가되었다.

## 범위와 주변 도구
React 자체는 UI 라이브러리이므로 라우팅, 서버 렌더링, 번들링은 Next.js나 Vite 같은 별도 도구와 함께 구성한다. 보통 `npm install react react-dom`으로 설치하며 Node.js 위에서 빌드 도구를 실행한다. 타입 검사가 필요하면 TypeScript로 컴포넌트를 작성한다.
