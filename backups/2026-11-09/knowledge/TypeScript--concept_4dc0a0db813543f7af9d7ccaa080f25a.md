# TypeScript

다른 이름: TS

주제: 컴퓨터 언어

JavaScript에 정적 타입 분석을 추가해 대규모 개발과 도구 지원을 개선하는 언어다.

## 내 정리

== JavaScript에 정적 타입 분석을 추가해 대규모 개발과 도구 지원을 개선하는 언어다. ==

## 용어

### 타입 소거

실행 코드에서 타입 표기를 제거하는 과정이다. 타입 검사를 수행하는 과정과 구분한다.

### 구조적 타입

명시적 상속 선언보다 값이 가진 필드·메서드 구조로 타입 호환성을 판단한다.

### any

해당 값에 대한 타입 검사를 크게 완화하는 타입으로, 오류 검출 능력을 낮출 수 있다.

### 타입 단언

개발자가 더 구체적인 타입을 지정하는 표기다. 실행 시 값을 변환하거나 검증하지 않는다.

### tsc

TypeScript 컴파일러 명령으로 타입 검사와 JavaScript 출력을 수행한다.

### tsgo

Go 기반 네이티브 TypeScript 도구 체인의 명령 이름이다.

## 기원
Microsoft의 Anders Hejlsberg가 주도했으며 2012년 10월 공개, 2014년 4월 1.0을 출시했다. 대규모 JavaScript 코드에서 오류를 일찍 찾고 자동완성·리팩터링을 개선하려는 목적에서 출발했다.

## JavaScript와의 관계
JavaScript 문법과 생태계를 기반으로 타입 표기를 확장한다. 기존 JavaScript 문법을 받아들이지만 모든 JavaScript 코드가 TypeScript의 타입 검사를 통과한다는 뜻은 아니다. 엄격한 검사 설정에서는 추가 오류가 발견될 수 있다.

타입 정보는 대체로 실행 전에 제거되며, 타입 자체가 런타임 입력 검증을 제공하지는 않는다. 다만 enum·namespace 등 일부 문법은 실행용 코드를 생성할 수 있다. `any`와 타입 단언은 검사 범위를 줄이므로 외부 JSON 등은 별도 검증이 필요하다.

## 활용과 구현 변화
==  브라우저 프론트엔드뿐 아니라 Node.js 등의 서버·CLI 개발에도 사용한다. 보통 JavaScript로 변환해 실행하며, 일부 실행 환경은 지원되는 TypeScript 문법을 직접 제거해 실행한다. 이때도 타입 검사를 별도로 수행해야 한다. == 

2025년 Microsoft는 컴파일러와 언어 서비스의 Go 포팅을 발표했다. 이는 개발 도구의 구현 언어를 바꾸는 작업이며 TypeScript 프로그램을 Go로 바꾸거나 Go 런타임에서 실행한다는 뜻이 아니다.
