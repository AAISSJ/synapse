# C++

다른 이름: CPP

주제: 컴퓨터 언어

C 기반 저수준 제어에 객체·제네릭·RAII를 결합한 다중 패러다임 언어다.

## 용어

### RAII

객체 수명과 자원 수명을 묶어 소멸 시점에 자원을 정리하는 관용구다.

### 템플릿

타입·값 매개변수로 코드를 일반화하는 C++의 컴파일 시점 기능이다.

### 정의되지 않은 동작

언어 명세가 결과를 보장하지 않는 실행으로 최적화와 결합해 예상 밖 결과를 낼 수 있다.

## Rust·Go가 비교 대상으로 삼는 언어
Bjarne Stroustrup이 1979년 C with Classes를 시작했고 이후 C++로 발전했다. 시스템·게임·엔진·고성능 서버에 폭넓게 사용된다.

현대 C++는 RAII와 스마트 포인터로 자원 관리를 개선한다. 다만 빌림·수명 규칙을 Rust와 같은 방식으로 언어 전체에 강제하지 않으므로 잘못된 참조와 데이터 레이스에 대한 책임이 남는다.

Rust는 안전성 검사를 강화하고, Go는 표현 방식과 언어 기능을 줄여 빌드·협업을 단순화하는 방향을 택했다. C++도 도구·빌드 설정과 코드 설계에 따라 생산성과 성능이 크게 달라진다.
