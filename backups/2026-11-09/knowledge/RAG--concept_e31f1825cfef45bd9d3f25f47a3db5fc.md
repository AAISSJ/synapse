# RAG

다른 이름: Retrieval-Augmented Generation · 검색 증강 생성

주제: AI · 에이전트

외부 자료를 검색해 모델 응답의 근거로 제공하는 구성 방식.

## 용어

### 임베딩

다른 이름: Embedding

텍스트 등을 벡터로 표현해 유사도 검색에 활용한다. 벡터 유사도 자체가 접근 권한이나 정답을 보장하지 않는다.

### ACL 필터

다른 이름: Access Control List

사용자·조직이 읽을 수 있는 문서만 검색·조회하도록 적용하는 권한 조건. 캐시와 원문 조회에도 일관되게 적용한다.

### 벡터 검색

임베딩의 유사도를 기준으로 관련 후보를 찾는다. pgvector 등으로 구현할 수 있으며 필터·정확도·성능을 함께 검증한다.

## 검색 증강 생성
RAG(Retrieval-Augmented Generation)는 질문과 관련된 자료를 검색해 모델의 응답 컨텍스트로 제공하는 구성 방식이다.

## 기본 흐름
1. 문서를 검색 단위로 나누고 임베딩을 생성한다.
2. 임베딩과 문서 메타데이터를 저장한다.
3. 질문과 유사한 문서를 검색한다.
4. 검색된 내용을 컨텍스트에 포함해 응답을 생성한다.

PostgreSQL+pgvector로 벡터 검색을 구현하고 테넌트·문서 ACL 조건을 결합할 수 있다. 검색 단계와 실제 원문 접근 모두에서 권한을 확인해야 한다.

==벡터 유사도는 접근 권한이나 사실의 정확성을 보장하지 않는다.== 검색 결과의 관련성·출처·최신성을 함께 검토한다.
